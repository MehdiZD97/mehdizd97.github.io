{%- comment -%} A YouTube video that loads only when played (PLAN 8.1). The thumbnail (from i.ytimg.com) links to the video on YouTube; with JavaScript, site.js turns it into a Play button that swaps in the player from youtube-nocookie.com, so nothing loads from YouTube before a click. Parameters: id (the YouTube ID); title, start (seconds), and lang default to the video's entry in _data/videos.yml; badge (corner text, such as the duration; defaults to the entry's duration or start time). The thumbnail is YouTube's 480 px `hqdefault` (no srcset: html-proofer 5.2 crashes on external srcset URLs and would skip the page). priority: true for a thumbnail at the top of a page (loaded at once, with high priority). {%- endcomment -%} {%- assign vp = site.data.videos.videos | where: "id", include.id | first -%} {%- assign vp_title = include.title | default: vp.title | default: "YouTube video" -%} {%- assign vp_start = include.start | default: vp.start -%} {%- assign vp_lang = include.lang | default: vp.language -%} {%- capture vp_badge -%} {%- if include.badge -%}{{ include.badge }} {%- elsif vp_start -%}from {% include timecode.html seconds=vp_start %} {%- elsif vp.duration -%}{% include timecode.html iso=vp.duration %} {%- endif -%} {%- endcapture -%} {%- assign vp_badge = vp_badge | strip -%} {%- assign vp_url = "https://www.youtube.com/watch?v=" | append: include.id -%} {%- if vp_start %}{% assign vp_url = vp_url | append: "&t=" | append: vp_start | append: "s" %}{% endif -%}
