ADMM for Downlink Beamforming in Cell-Free Massive MIMO Systems

{%- when "type-body" %}

In cell-free massive MIMO systems with multiple distributed access points (APs) serving multiple users over the same time-frequency resources, downlink beamforming is done through spatial precoding. Precoding vectors can be optimally designed to use the minimum downlink transmit power while satisfying a quality-of-service requirement for each user.
